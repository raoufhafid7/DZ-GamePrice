# DZ GamePrice

نسخة Front-end جاهزة لمنصة مقارنة أسعار Gaming في الجزائر.

## التشغيل
افتح `index.html` مباشرة في المتصفح، أو ارفع المجلد إلى أي استضافة Static.

## ما الموجود؟
- Dark Gaming UI متجاوب للهاتف والكمبيوتر
- صفحة رئيسية
- بحث فوري
- تصنيفات
- فلاتر السعر والفئة
- بطاقات المنتجات
- صفحة مقارنة أسعار داخل الواجهة
- قسم PC Builder
- تصميم RTL عربي
- بيانات تجريبية جاهزة للاستبدال بقاعدة بيانات/API

## الخطوة التالية للإنتاج
اربط المنتجات والمتاجر والأسعار بقاعدة بيانات وAPI، وأضف لوحة Admin لتحديث الأسعار وجدولة جلبها من المتاجر.
